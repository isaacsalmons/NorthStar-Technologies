Document 6 - Configurations
NorthStar Technologies - Tier 3 Campus Network
6.1 All Devices — Basic Configuration
Complete on every router and switch.
1. Set the correct hostname.
2. Configure an enable secret.
3. Configure local administrative credentials.
4. Configure the domain name northstar.local.
5. Disable unnecessary DNS lookup behavior.
6. Enable password encryption.
7. Configure an appropriate login banner.
8. Configure SSHv2.
9. Generate the required RSA keys.
10. Disable Telnet and allow SSH only.
11. Ensure VLAN 10 management infrastructure is available for later device management configuration.
Pre/Post Checks
show running-config
show ip ssh
*after saving*
show startup-config 
*for layer 3 switches*
show ip route

EDGE01 Configuration
enable
configure terminal
hostname <hostname>
enable secret <password>
username <username> secret <password>
ip domain-name northstar.local
no ip domain-lookup
crypto key generate rsa
2048
ip ssh version 2
service timestamps log datetime msec
interface loopback0
ip address <x.x.x.x> 255.255.255.255
ip access-list standard SSH-ACL
permit 10.10.10.0 0.0.0.255
permit 10.20.10.0 0.0.0.255
exit
line console 0
logging synchronous 
login local
line vty 0 15
login local
transport input ssh
access-class SSH-ACL in
end

6.2 CORE01 / CORE02 — Core Layer
1. Configure all core-to-core and core-to-distribution interfaces as Layer 3 routed links.
2. Assign /30 addresses from Document 4.
3. Configure OSPF Process 10, Area 0.
4. Configure the correct OSPF router ID.
5. Advertise connected networks through OSPF.
6. Establish OSPF adjacencies with all connected distribution switches.
7. Establish the CORE01 ↔ CORE02 OSPF adjacency.
8. Configure loopbacks for OSPF router IDs and advertise them via OSPF.
9. Ensure the core learns all Building A and Building B networks.
10. Ensure redundant paths exist to both buildings.
11. Configure interface descriptions.

6.3 DIST01 / DIST02 — Building A Distribution
1. Create the required VLANs statically.
2. Configure distribution-to-core links as Layer 3.
3. Assign /30 addresses.
4. Configure OSPF Process 10, Area 0.
5. Establish OSPF adjacencies with CORE01 and CORE02.
6. Create loopback interfaces and advertise them via OSPF
7. Create SVIs for Building A VLANs 10–120.
8. Advertise SVI’s to OSPF.
9. Assign .2 and .3 SVI addresses.
10. Configure HSRP for every Building A VLAN.
11. Distribute HSRP active roles between DIST01 and DIST02.
12. Configure DHCP relay to NS-DHCP01.
13. Configure the DIST01 ↔ DIST02 interconnect.
14. Configure Rapid PVST+.
15. Align STP root roles with HSRP active roles.
16. Configure appropriate access-layer trunks.


Goal: Building A gateways, HSRP, STP, DHCP relay, and core connectivity.
